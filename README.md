# poc-vault

### Check version:
python --version

### Python 3.10+ - highly welcome

### How to run: Python

Put it in a file like ignite_log_analyzer.py, place your logs (ignite1.log, ignite2.log) in the same folder, then run:

python ignite_log_analyzer.py


### How to run: Java version as alternative:

javac com.loganalyzer.IgniteLogAnalyzer.java
java com.loganalyzer.IgniteLogAnalyzer ignite1.log ignite2.log
